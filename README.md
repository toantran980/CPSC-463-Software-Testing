# CPSC 463 - Software Testing

Course projects for Software Testing at CSUF. Includes unit testing, Selenium automation, and keyword-driven testing with Robot Framework.

## Projects

### Odoo Lunch Module Tests
- `test_selenium_lunch.py` - Selenium tests (positive/negative)
- `test_unittest_lunch.py` - Unit tests with Odoo framework
- `test_keyword_driven_lunch.robot` - Robot Framework keyword-driven tests
